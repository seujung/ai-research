# 알고리즘

Cormen, Leiserson, Rivest, Stein의 *Introduction to Algorithms* 4판(MIT Press, 2022)을 장 단위로 정리합니다.
흔히 저자 이름의 머리글자를 따서 CLRS라고 부릅니다.
이 책은 8부로 나뉩니다. 1부에서 분석 도구를 세우고, 2~5부에서 정렬과 자료 구조, 설계 기법을 다룹니다.
6부는 그래프 알고리즘, 7부는 병렬·온라인·수치·정수론·문자열·머신러닝·NP-완전성·근사 알고리즘을 다룹니다.

각 장은 원문을 번역하지 않습니다. 알고리즘마다 아이디어, 짧은 Python 코드, 정확성 논증, 실행 시간 분석을 적습니다.
그리고 손으로 따라갈 수 있는 작은 입력으로 실행 과정을 표와 그림으로 보여 줍니다.
연습 문제와 일부 별표(★) 절은 생략했습니다. 생략한 절은 각 장 첫머리에 적었습니다.

!!! info "원문과 자료"

    - 책: Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, Clifford Stein, *Introduction to Algorithms*, 4th ed., MIT Press, 2022.
    - 책 페이지: <https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/>
    - 이 노트의 본문, 코드, 그림은 원문을 참고해 새로 작성했습니다. 책의 그림을 옮기지 않았습니다.
    - 부록(합, 집합, 계수와 확률, 행렬)은 따로 정리하지 않습니다. 필요한 내용은 [수학](../../math/index.md) 섹션의 교재로 연결합니다.

## 읽는 방법

1부는 모든 장의 전제입니다. 특히 2장의 루프 불변식, 3장의 점근 표기, 4장의 마스터 정리를 먼저 읽습니다.
2부와 3부는 순서대로 읽는 편이 좋습니다. 13장의 레드-블랙 트리는 12장의 이진 탐색 트리를 전제로 합니다.
4부의 동적 계획법과 탐욕 알고리즘은 6부의 최단 경로와 최소 신장 트리에서 다시 쓰입니다.
6부는 20장을 먼저 읽고, 21~25장은 관심 있는 순서로 읽어도 됩니다.
7부의 각 장은 대체로 독립적입니다. 34장과 35장은 이어서 읽습니다.
