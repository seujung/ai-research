# 컴퓨터 과학

알고리즘, 자료 구조, 계산 복잡도처럼 컴퓨터 과학의 기초를 교재 한 권씩으로 정리합니다.
각 개념이 어떤 문제를 풀고, 왜 맞으며, 얼마나 빠른지를 함께 적습니다.

이 섹션은 "계산을 어떻게 설계하고 분석하는가"를 다룹니다.
알고리즘 분석에 쓰는 수학 자체(확률, 선형대수, 최적화 이론)는 [수학](../math/index.md) 섹션에 둡니다.
신경망과 LLM에 특화한 계산 기법은 [AI](../ai/index.md) 섹션에 둡니다.

## 주제

| 주제 | 교재 | 상태 | 정리 |
| --- | --- | --- | --- |
| 알고리즘 | Cormen, Leiserson, Rivest, Stein, *Introduction to Algorithms*, 4th ed. | 1~35장 정리 | [바로 가기](algorithms/index.md) |

## 새 주제를 추가하는 방법

1. 주제가 이 섹션에 속하는지 확인합니다. 수학 이론 교재는 `docs/math/`, 신경망 교재는 `docs/ai/` 에 둡니다.
2. `docs/cs/` 아래에 주제 이름을 딴 디렉토리를 만들고 `index.md` 에 교재 개요와 목차를 적습니다.
3. 장별 문서는 `01-`, `02-` 처럼 번호를 앞에 붙입니다.
4. `mkdocs.yml` 의 `nav` 에 새 항목을 추가합니다.
