## 새 리뷰를 추가하는 방법

1. `docs/papers/` 아래에 `YYYY-slug.md` 형식으로 파일을 만듭니다. `YYYY`는 논문 발표 연도이고, `slug`는 영문 약칭입니다. 예: `2017-attention.md`
2. 아래 리뷰 틀을 복사해 내용을 채웁니다.
3. 위 목록 표에 한 줄을 추가합니다.
4. `mkdocs.yml`의 `nav`에서 `논문` 아래에 항목을 추가합니다.
