# 확률론

Michael J. Evans와 Jeffrey S. Rosenthal의 *Probability and Statistics: The Science of Uncertainty*
(2nd Edition, W. H. Freeman, 2010)를 장 단위로 정리합니다.
각 장은 책의 절 순서를 따르고, **핵심 개념과 책에 나오는 대표 예제**를 중심으로 구성합니다.
정의와 정리를 먼저 세우고, 예제를 직접 계산하고, 시뮬레이션 삽화로 의미를 확인합니다.
예제의 수치는 모두 Python(NumPy, SciPy)으로 다시 계산해서 검증했습니다.

이 책은 1–4장에서 확률론을, 5–10장에서 통계적 추론을 다룹니다.
11장은 확률 과정을 다루며, 1–4장의 내용에만 의존합니다.
이 노트는 확률론을 먼저 묶어 정리합니다. 1–4장과 11장을 노트 1–5장에 둡니다.
통계적 추론인 교재 5–10장은 노트 6–11장에 둡니다.

## 교차 엔트로피가 언어 모델의 손실 함수인 이유

정답 분포 $p$ 와 모델의 예측 분포 $q$ 사이의 쿨백-라이블러 발산은 다음과 같습니다.

$$
D_{\mathrm{KL}}(p \parallel q) = \sum_{x} p(x) \log \frac{p(x)}{q(x)}
= \underbrace{-\sum_{x} p(x) \log q(x)}_{H(p,\,q)} - \underbrace{\left(-\sum_{x} p(x) \log p(x)\right)}_{H(p)}
$$

정답 분포 $p$ 는 학습 과정에서 고정되어 있으므로 $H(p)$ 도 상수가 됩니다.
따라서 쿨백-라이블러 발산을 최소화하는 문제는 교차 엔트로피 $H(p, q)$ 를
최소화하는 문제와 완전히 같아집니다.
$D_{\mathrm{KL}}(p \parallel q) \ge 0$ 이라는 사실은 [3장의 젠센 부등식](03-expectation.md)에서 나옵니다.
