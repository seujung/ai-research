# 물리

양자역학처럼 자연을 수식으로 기술하는 물리 교재를 한 권씩 정리합니다.
개념마다 수식을 끝까지 유도하고, 실제 숫자를 넣은 예시와 그림으로 확인합니다.

이 섹션은 "자연의 법칙을 어떻게 수식으로 쓰고 예측하는가"를 다룹니다.
유도에 쓰는 수학 자체(선형대수, 확률, 최적화 이론)는 [수학](../math/index.md) 섹션에 둡니다.
물리에서 빌려 온 계산 기법을 신경망에 적용하는 내용은 [AI](../ai/index.md) 섹션에 둡니다.

## 주제

| 주제 | 교재 | 상태 | 정리 |
| --- | --- | --- | --- |
| 양자역학 | Griffiths, *Introduction to Quantum Mechanics*, 1st ed. | 1~11장, 맺음말 정리 | [바로 가기](quantum-mechanics/index.md) |

## 새 주제를 추가하는 방법

1. 주제가 이 섹션에 속하는지 확인합니다. 수학 이론 교재는 `docs/math/`, 신경망 교재는 `docs/ai/` 에 둡니다.
2. `docs/physics/` 아래에 주제 이름을 딴 디렉터리를 만들고 `index.md` 에 교재 개요와 목차를 적습니다.
3. 장별 문서는 `01-`, `02-` 처럼 번호를 앞에 붙입니다.
4. `mkdocs.yml` 의 `nav` 에 새 항목을 추가합니다.
