# 서적

읽고 있거나 읽은 책을 장 단위로 정리합니다. 책 한 권이 하나의 디렉토리에 대응하고,
디렉토리 안의 문서가 장 순서대로 배열됩니다.

## 목록

| 책 | 상태 | 정리 |
| --- | --- | --- |
| 신경망 기초 | 1~7장 정리 | [바로 가기](book-of-llms/index.md) |

## 새 책을 추가하는 방법

1. `docs/books/` 아래에 책 이름을 딴 디렉토리를 만듭니다.
2. 그 안에 `index.md` 를 두고 책의 개요와 목차를 적습니다.
3. 장별 문서는 `01-`, `02-` 처럼 번호를 앞에 붙여서 정렬 순서를 명확하게 합니다.
4. `mkdocs.yml` 의 `nav` 에 새 항목을 추가합니다.
