# 1. 토크나이제이션

텍스트를 모델이 처리할 수 있는 정수 시퀀스로 변환하는 과정을 다룹니다.

## 바이트 페어 인코딩

BPE는 가장 자주 등장하는 인접 기호 쌍을 반복적으로 병합해서 어휘를 만들어 나갑니다.
어휘 크기를 $V$ 라고 할 때, 병합 규칙의 개수는 초기 기호 집합의 크기를 뺀 값이 됩니다.

!!! note "왜 바이트 단위에서 시작하는가"

    유니코드 문자 단위로 시작하면 어휘에 없는 문자가 등장했을 때 처리할 방법이 없습니다.
    바이트 단위로 시작하면 256개의 기호로 모든 입력을 표현할 수 있기 때문에,
    미등록 토큰 문제가 원천적으로 발생하지 않습니다.

## 구현 시 확인할 점

```python
import tiktoken

tokenizer = tiktoken.get_encoding("gpt2")
ids = tokenizer.encode("안녕하세요, AI Research 입니다.")
print(ids, len(ids))
```

한국어는 대부분 여러 바이트로 분해되기 때문에, 같은 의미의 문장이라도 영어보다
토큰 수가 훨씬 많아집니다. 비용을 추정할 때 이 차이를 반드시 반영해야 합니다.
