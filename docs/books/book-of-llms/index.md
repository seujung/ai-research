# 신경망 기초

다층 퍼셉트론부터 학습률까지, LLM을 이해하는 데 필요한 신경망의 기본기를 정리합니다.
각 장은 결론을 외우는 대신 **수식을 끝까지 따라가는 방식**으로 구성했고, 개념마다 그림을 붙여
식이 말하는 내용을 눈으로 확인할 수 있게 했습니다.

## 목차

| 장 | 다루는 내용 |
| --- | --- |
| [1. 다층 퍼셉트론](01-mlp.md) | 뉴런을 초평면으로 해석하고, 은닉층이 공간을 접어 XOR을 푸는 과정을 따라갑니다. |
| [2. 활성화 함수](02-activations.md) | 비선형성이 필요한 이유를 증명하고, 기울기 소실과 softmax, GLU를 분석합니다. |
| [3. 그래디언트](03-gradients.md) | 미분에서 헤시안까지 정의하고, 신경망 한 층과 softmax + 교차 엔트로피의 그래디언트를 유도합니다. |
| [4. 역전파](04-backprop.md) | 역방향 계산이 효율적인 이유와 2층 MLP의 전체 유도, 그래디언트 검증이 실패하는 경우를 다룹니다. |

| [6. 손실 함수](06-loss.md) | 손실마다 최적 해가 어떻게 달라지는지, 그리고 확률 모델의 어떤 가정과 대응하는지 유도합니다. |

## 읽는 방법

앞 장의 결과를 뒤 장에서 가져다 쓰므로 순서대로 읽는 편이 좋습니다. 특히 3장에서 유도한
연쇄 법칙과 야코비안 규칙은 4장 이후 모든 장의 바탕이 됩니다.

본문의 수치 예시와 그림은 모두 직접 계산해서 만들었고, 유도한 식은 수치 미분으로 검증했습니다.
