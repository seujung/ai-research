# 6. 경사 하강법과 학습률

## 갱신 규칙

앞 장에서 구한 그래디언트는 손실이 가장 가파르게 **증가**하는 방향을 가리킵니다.
따라서 손실을 줄이려면 그 반대 방향으로 움직입니다.

$$
\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)
$$

여기서 $\eta$ 가 학습률입니다. 방향은 그래디언트가 정해 주므로, **학습률이 정하는
것은 오직 보폭 하나뿐입니다.** 그런데 이 하나가 학습의 성패를 가릅니다.

한 가지 짚어 둘 점이 있습니다. 그래디언트는 **아주 작은 이동에 대해서만** 유효한
정보입니다. 멀리 움직이면 그 지점의 그래디언트는 이미 다른 값이 되어 있습니다.
보폭이 커질수록 예측이 빗나가는 이유가 여기에 있습니다.

## 배치를 나누는 방식

| 방식 | 한 스텝에 쓰는 표본 | 특징 |
| --- | --- | --- |
| 배치 경사 하강법 | 전체 | 방향이 정확하지만 한 스텝이 비쌉니다. |
| 확률적 경사 하강법 | 1개 | 스텝이 싸지만 방향이 크게 흔들립니다. |
| 미니배치 | 수십에서 수천 개 | 둘의 절충이며 실제로는 거의 항상 이 방식을 씁니다. |

미니배치의 그래디언트는 전체 그래디언트의 **불편 추정량**입니다. 평균적으로는
올바른 방향을 가리키되 매번 조금씩 어긋납니다. 이 잡음은 손해로만 작용하지 않습니다.
평평한 안장점 근처에서 빠져나오는 데 도움이 되기도 합니다.

## 학습률의 안정 조건

손실이 이차 함수 $f(x) = \frac{1}{2} x^\top A x$ 인 경우에는 안정 조건을 정확히
계산할 수 있습니다. 갱신식을 전개하면 다음과 같습니다.

$$
x_{t+1} = x_t - \eta A x_t = (I - \eta A)\, x_t
$$

$A$ 의 고유값을 $\lambda_i$ 라 하면, 각 고유 방향의 성분은 매 스텝
$(1 - \eta \lambda_i)$ 배가 됩니다. 모든 방향이 줄어들려면 다음이 성립해야 합니다.

$$
\lvert 1 - \eta \lambda_i \rvert < 1 \quad \text{모든 } i \qquad \Longleftrightarrow \qquad
0 < \eta < \frac{2}{\lambda_{\max}}
$$

**가장 큰 고유값 하나가 학습률의 상한을 결정합니다.**

### 실행 코드

```python title="lr.py"
import numpy as np

# f(x) = 0.5 x^T A x  (최솟값은 원점)
A = np.array([[10.0, 0.0],
              [0.0,  1.0]])
eig = np.linalg.eigvalsh(A)
L, mu = eig.max(), eig.min()
print("[문제 설정]  f(x) = 0.5 x^T A x")
print(f"  고유값        = {eig}")
print(f"  최대 고유값 L = {L}, 최소 고유값 mu = {mu}")
print(f"  조건수 L/mu   = {L/mu:.1f}")
print(f"  수렴 조건     = eta < 2/L = {2/L:.4f}")

def run(eta, steps=60, x0=np.array([1.0, 1.0])):
    x = x0.copy()
    for _ in range(steps):
        x = x - eta * (A @ x)
        if not np.all(np.isfinite(x)) or np.abs(x).max() > 1e12:
            return x, False
    return x, True

d0 = np.linalg.norm(np.array([1.0, 1.0]))
print(f"\n[학습률별 결과] 60스텝 후 원점까지의 거리 (시작 거리 {d0:.4f})")
for eta in [0.01, 0.05, 0.1, 0.18, 0.19, 0.2, 0.21, 0.3]:
    x, ok = run(eta)
    dist = np.linalg.norm(x)
    if not ok:                verdict = "발산"
    elif dist >= d0:          verdict = "진동 또는 발산"
    elif dist < 1e-6:         verdict = "수렴 (매우 빠름)"
    elif dist < 1e-2:         verdict = "수렴"
    else:                     verdict = "느리게 수렴"
    mark = "" if eta < 2/L else "   <- 2/L 이상"
    print(f"  eta={eta:5.2f}  거리={dist:12.4e}  {verdict}{mark}")
```

### 실행 결과

```text

  고유값        = [ 1. 10.]
  최대 고유값 L = 10.0, 최소 고유값 mu = 1.0
  조건수 L/mu   = 10.0
  수렴 조건     = eta < 2/L = 0.2000

[학습률별 결과] 60스텝 후 원점까지의 거리 (시작 거리 1.4142)
  eta= 0.01  거리=  5.4716e-01  느리게 수렴
  eta= 0.05  거리=  4.6070e-02  느리게 수렴
  eta= 0.10  거리=  1.7970e-03  수렴
  eta= 0.18  거리=  6.9146e-06  수렴
  eta= 0.19  거리=  1.7970e-03  수렴
  eta= 0.20  거리=  1.0000e+00  느리게 수렴   <- 2/L 이상
  eta= 0.21  거리=  3.0448e+02  진동 또는 발산   <- 2/L 이상
  eta= 0.30  거리=  1.0995e+12  발산   <- 2/L 이상
```

### 결과에서 짚어 볼 점

**이론이 예측한 경계 0.2가 실험에서 그대로 나타났습니다.**

- $\eta = 0.19$ 까지는 수렴합니다.
- $\eta = 0.20$ 에서는 거리가 정확히 1.0에 머뭅니다. $1 - \eta\lambda_{\max} = -1$ 이라
  부호만 바뀌고 크기는 그대로인 상태, 즉 **영원히 같은 두 점을 오가는 진동**입니다.
- $\eta = 0.21$ 부터는 거리가 커지고, $\eta = 0.30$ 에서는 60스텝 만에 $10^{12}$ 를 넘습니다.

경계를 아주 조금 넘겼을 뿐인데 결과가 완전히 달라집니다. 학습률을 키울 때
손실이 서서히 나빠지는 것이 아니라 **어느 지점을 지나면 갑자기 무너지는** 이유입니다.

## 조건수가 만드는 지그재그

가장 큰 고유값이 학습률의 상한을 정하는데, 수렴 속도는 **가장 작은 고유값**이
좌우합니다. 두 값의 비율인 조건수 $\kappa = \lambda_{\max} / \lambda_{\min}$ 가
크면 학습이 괴로워집니다.

```text
[조건수가 만드는 지그재그]  eta=0.18, 처음 6스텝
  step        x1 (가파른 축)        x2 (완만한 축)
     0          1.000000          1.000000
     1         -0.800000          0.820000
     2          0.640000          0.672400
     3         -0.512000          0.551368
     4          0.409600          0.452122
     5         -0.327680          0.370740
     6          0.262144          0.304007
```

**`x1` 은 매 스텝 부호를 바꾸며 튀고, `x2` 는 한 번에 18퍼센트씩만 줄어듭니다.**
학습률을 더 키워서 `x2` 를 빨리 줄이고 싶어도 `x1` 이 먼저 발산하기 때문에 불가능합니다.
가장 가파른 방향에 맞춰 보폭을 정할 수밖에 없고, 그 결과 완만한 방향은
조건수 배만큼 느리게 움직입니다.

앞 장에서 보았듯 고차원 손실 표면에는 이런 곡률 차이가 흔합니다.
**차원마다 보폭을 다르게 가져가는 적응적 옵티마이저가 필요한 근본적인 이유입니다.**

## 모멘텀

모멘텀은 과거의 이동 방향을 관성처럼 누적합니다.

$$
v_t = \beta v_{t-1} + \nabla L(\theta_t), \qquad
\theta_{t+1} = \theta_t - \eta v_t
$$

그래디언트가 여러 스텝 동안 같은 방향을 가리키면 $v$ 가 쌓여 보폭이 커지고,
지그재그처럼 부호가 번갈아 바뀌면 서로 상쇄됩니다.

```text
[모멘텀 효과] beta=0.9, 60스텝 후 거리
  모멘텀은 걸음 폭을 실질적으로 eta/(1-beta) = 10배로 키웁니다.
  따라서 안정 한계도 2/L=0.20 가 아니라 그 10분의 1 근처로 내려갑니다.

     eta     실효 eta          모멘텀 없음          모멘텀 사용  판정
   0.002      0.020      9.3540e-01      2.9507e-01  모멘텀이 유리
   0.005      0.050      7.4169e-01      4.7524e-02  모멘텀이 유리
   0.010      0.100      5.4716e-01      3.8275e-02  모멘텀이 유리
   0.050      0.500      4.6070e-02      4.4534e-02  모멘텀이 유리
   0.100      1.000      1.7970e-03      4.8791e-02  모멘텀이 불리 (실효 학습률 과다)
```

### 결과에서 짚어 볼 점

**모멘텀은 무조건 좋은 것이 아닙니다.** $\eta = 0.1$ 에서는 모멘텀을 쓴 쪽이
27배나 나쁩니다.

이유는 실효 학습률에 있습니다. 그래디언트가 일정하다고 가정하면 $v$ 는 등비급수로
수렴해서 $\frac{1}{1-\beta}$ 배가 됩니다. $\beta = 0.9$ 면 10배입니다.
따라서 $\eta = 0.1$ 은 실제로 보폭 1.0으로 움직이는 셈이고, 이는 안정 한계인
0.2를 크게 넘습니다.

**모멘텀을 켜면 학습률을 함께 낮춰야 합니다.** 기존 설정에 모멘텀만 추가했다가
학습이 불안정해지는 일이 흔한데, 원인은 대개 여기에 있습니다.

## 학습률 스케줄

학습 초반에는 크게 움직이고 후반에는 정밀하게 다듬는 편이 유리하다는 발상입니다.

| 스케줄 | 형태 |
| --- | --- |
| 고정 | 처음부터 끝까지 같은 값 |
| 계단식 감쇠 | 정해진 스텝마다 10분의 1로 |
| 코사인 | $\eta_0 \cdot \frac{1}{2}\left(1 + \cos\frac{\pi t}{T}\right)$ |
| 워밍업 + 코사인 | 초반에 0부터 선형으로 올린 뒤 코사인으로 감소 |

```text
[스케줄별 학습률]
              스텝         0        50       100       250       500       750       999
            고정     0.10000   0.10000   0.10000   0.10000   0.10000   0.10000   0.10000
        계단식 감쇠     0.10000   0.10000   0.10000   0.10000   0.01000   0.01000   0.00100
           코사인     0.10000   0.09938   0.09755   0.08536   0.05000   0.01464   0.00000
       워밍업+코사인     0.00100   0.05100   0.10000   0.09330   0.05868   0.01786   0.00000
```

워밍업이 필요한 이유는 **초기화 직후가 가장 위험하기 때문입니다.** 학습 시작
시점의 그래디언트는 크고 방향도 신뢰하기 어렵습니다. 여기서 큰 보폭으로 움직이면
회복하기 어려운 지점으로 떨어질 수 있습니다. Adam 계열은 초반 몇 스텝 동안
2차 모멘트 추정이 불안정해서 더욱 그렇습니다.

### 실제로 적용해 보면

```text
[스케줄별 학습 결과] 1000스텝
           스케줄         최종 손실         최저 손실      정확도
            고정      0.011881      0.011881     1.00
        계단식 감쇠      0.034613      0.034613     1.00
           코사인      0.029241      0.029241     1.00
       워밍업+코사인      0.029197      0.029197     1.00
```

!!! warning "이 결과를 일반화하면 안 됩니다"

    **고정 학습률이 가장 낮은 손실을 냈습니다.** 스케줄이 쓸모없다는 뜻이 아니라,
    **이 실험이 스케줄의 이점이 드러나는 조건을 갖추지 못했기 때문입니다.**

    여기서 쓴 XOR 문제는 표본이 4개뿐이고 잡음이 없으며 전체 배치로 학습합니다.
    그래디언트가 매 스텝 정확하므로 후반에 보폭을 줄일 이유가 없고, 줄이면
    수렴만 늦어집니다.

    스케줄이 의미를 갖는 것은 미니배치 잡음이 있을 때입니다. 최적점 근처에서
    보폭이 크면 잡음 때문에 주변을 맴돌 뿐 더 내려가지 못하는데, 이때 보폭을
    줄이면 그 진폭이 함께 줄어듭니다. **줄일 잡음이 없으면 얻을 것도 없습니다.**

    작은 문제에서 얻은 결과를 큰 학습에 그대로 옮기면 안 되는 사례입니다.

## 학습률을 고르는 실제 방법

```text
[학습률이 너무 크면] 같은 모델, 학습률만 바꿔서 300스텝
       lr           최종 손실  판정
     0.05        0.158223  느림
     0.50        0.007126  정상 수렴
     5.00        1.044428  학습 실패 (무작위 수준 이상)
    50.00       13.404645  학습 실패 (무작위 수준 이상)
```

학습률 `5.0` 의 손실 1.044는 앞 장에서 계산한 무작위 추측의 기준선
$\ln 2 = 0.693$ 보다도 **높습니다.** 학습을 300스텝 진행하고도 아무것도 모르는
상태보다 나쁜 자리에 있다는 뜻입니다.

여기서 실용적인 지침이 나옵니다.

- **좋은 학습률은 한 점이 아니라 구간입니다.** 위 실험에서 `0.5` 근처가 잘 동작했고,
  `0.05` 는 느릴 뿐 틀리지는 않았습니다. 10배 단위로 훑어서 구간을 찾은 다음
  그 안에서 조정하는 편이 효율적입니다.
- **손실이 발산하면 학습률을 먼저 의심하십시오.** 구현 오류를 찾기 전에
  학습률을 10분의 1로 줄여 보는 것이 훨씬 빠릅니다.
- **초기 손실을 $\ln k$ 와 비교하십시오.** 시작값이 맞지 않으면 학습률 문제가
  아니라 구현이나 데이터 문제입니다.
- **모멘텀이나 옵티마이저를 바꿀 때는 학습률도 함께 조정하십시오.**
  앞에서 보았듯 실효 보폭이 달라집니다.

## 정리

| 개념 | 핵심 |
| --- | --- |
| 학습률 | 방향이 아니라 보폭만 정합니다. |
| 안정 조건 | 이차 근사에서 $\eta < 2/\lambda_{\max}$ 이며, 넘기면 급격히 무너집니다. |
| 조건수 | 수렴 속도를 좌우하며, 클수록 지그재그가 심해집니다. |
| 모멘텀 | 실효 보폭을 $1/(1-\beta)$ 배로 키우므로 학습률을 함께 낮춰야 합니다. |
| 스케줄 | 미니배치 잡음이 있을 때 의미가 있고, 워밍업은 초기 불안정을 막습니다. |
