# 양자역학 교재 수식 전개 보강 설계

작성일: 2026. 11. 23.

## 의도

사용자는 `docs/physics/quantum-mechanics/` 의 12개 장이 전체적으로 어렵다고 말했습니다. 원인은 주제의 난이도만이 아닙니다. 유도에서 중간 계산이 문장 한 줄로 생략된 곳이 많습니다. 초보자는 식 A 다음 줄 식 B 로 넘어갈 때 무엇을 했는지 알 수 없습니다.

이 작업은 각 장에서 생략된 전개를 본문에 직접 펼치고, 어려운 개념마다 도해를 더합니다. 목표는 미분 방정식, 복소수, 선형대수의 기초를 아는 독자가 각 줄을 스스로 따라갈 수 있는 상태입니다.

## 목표

1. 생략된 중간 계산을 본문 식으로 넣습니다. 각 새 줄에 "무엇을 했는지" 한 문장을 붙입니다.
2. 개념을 눈으로 잡아야 하는 곳에 도해를 추가합니다. 장당 2개 안팎입니다.
3. 기존 사실, 수치, 양태, 논리 관계를 그대로 보존합니다.

## 비목표

- 장 구조를 다시 설계하지 않습니다. 절 순서와 소제목은 유지합니다.
- 연습 문제를 추가하지 않습니다.
- 원문에 없는 새 물리 내용을 만들지 않습니다. 계산 단계만 펼칩니다.
- 모든 식을 처음 원리부터 유도하지 않습니다. 미적분 교과서 수준의 표준 적분은 결과를 쓰되, 대입 과정을 보입니다.

## 제약

- 한국어 출력 스타일(합쇼체, 짧은 문장, 한 개념에 한 용어)을 따릅니다.
- 수식은 기존처럼 `$$ ... $$` 블록과 인라인 `$...$` 를 씁니다. MathJax 설정은 `\boldsymbol` 만 추가 로드합니다. 새 매크로를 쓰지 않습니다.
- 그림은 프로젝트 `.venv` 에 matplotlib 이 없으므로 별도 venv 에서 생성합니다. 한글 글꼴은 `Apple SD Gothic Neo` 를 씁니다. 기존 그림과 같은 흰 배경, 1800px 폭, 같은 색 계열(파랑 `#2a76d2`, 주황 `#e7832b`, 초록 `#308e58`, 빨강 `#a03c42`)을 씁니다.
- 그림 생성 스크립트는 저장소에 넣지 않습니다. 기존 관례가 PNG 만 두는 방식이기 때문입니다.
- `mkdocs build --strict` 로 링크와 빌드를 확인합니다.

## 방식

사용자가 고른 방식입니다. 세 안 중 "단계별 전개 + 개념 그림"입니다.

### 본문 전개 형식

생략된 계산은 다음 모양으로 씁니다.

1. 무엇을 대입하는지 밝힙니다.
2. 중간 식을 `$$` 블록으로 보입니다.
3. 각 블록 앞이나 뒤에 한 문장으로 조작을 설명합니다(예: "부분 적분합니다. $xJ$ 는 양 끝에서 0이므로 경계항이 사라집니다.").
4. 마지막에 기존 결과 식을 둡니다. 기존 결과 식은 위치와 번호를 바꾸지 않습니다.

예시(1장 333줄 부근):

```
기존: 앞 절의 연속 방정식에 부분 적분을 두 번 적용하면 다음 식이 나옵니다.

수정:
연속 방정식 $\partial_t |\Psi|^2 = -\partial_x J$ 를 넣습니다.

$$ \frac{d\langle x\rangle}{dt} = \int x \left(-\frac{\partial J}{\partial x}\right) dx $$

부분 적분합니다. 확률 흐름 $J$ 는 $x \to \pm\infty$ 에서 0이므로 경계항이 사라집니다.

$$ = \int J\, dx $$

$J = \frac{i\hbar}{2m}(\Psi^* \partial_x \Psi - \partial_x \Psi^* \Psi)$ 를 넣고 정리합니다.

$$ = -\frac{i\hbar}{m}\int \Psi^* \frac{\partial \Psi}{\partial x} dx $$
```

### 그림 형식

도해가 값을 하는 곳에만 넣습니다. 그림 하나에 개념 하나입니다. 기존 그림 캡션과 같은 `<figure markdown>` 구조와 `fig-title` 을 씁니다.

- 그림 번호는 장 안에서 다시 매깁니다. 새 그림을 중간에 넣으면 뒤 번호가 밀립니다.
- 캡션은 두 문단으로 씁니다. 첫 줄은 제목, 둘째 줄은 무엇을 보는지와 수치입니다.
- 도해 종류: 계산 흐름도(어떤 식에 무엇을 대입하는지), 기하 그림(적분 구간, 벡터 분해, 경계 조건), 함수 모양 그림(피적분 함수, 근사와 정확한 해의 비교).

## 확인 방법

1. 각 장을 고친 뒤 `mkdocs build --strict` 를 실행합니다.
2. 손계산 수치는 `sympy`/`numpy` 로 다시 검증합니다. 기존 수치와 다르면 기존 수치를 의심하고 원인을 확인합니다.
3. 새 그림은 PNG 를 열어 한글 글꼴 깨짐(¤ 문자), 로그 축 눈금, 겹침을 확인합니다.
4. 기존 장 전체를 재읽기하며 다음을 봅니다. 첫 문장이 요점인지, 마지막 문장이 새 정보인지, 같은 조사 반복, 양태 변화.
5. 한국어 린터(`ko-ste-lint.py`)를 각 장에 실행하고, 인용문 때문에 생기는 권고는 무시합니다.
